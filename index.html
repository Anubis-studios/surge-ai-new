Security: paste a GitHub Personal Access Token (it's used only in this browser, never shipped in the generator source) to list, pick or create a repository and push your library as surge-creations.json.

If you see “Resource not accessible by personal access token”, your token lacks permission. Best: make a classic token (GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)) and tick the repo scope (plus read:user). Fine-grained tokens need repository access with Contents: Read and write (to push) and Administration: Read and write (to create repos).
